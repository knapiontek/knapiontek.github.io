# library/products

One file per product group, its products by key: as the shop sells them (name, price, unit, shop, links) and as the maker
sizes them.

| File | What |
|---|---|
| `appliances.json` | oven, microwave, fridge, dishwasher, hob, hood, sink, coffee machine |
| `boards.json` | boards, worktops, panels: decor, thickness, sheet size |
| `building.json` | building work: plasterboard and its profiles, sealants, pipes and riser, an access hatch, the WC door |
| `fasteners.json` | confirmats, connectors, screws, dowels, brackets |
| `hardware.json` | hinges, drawers and runners, handles, legs, plinth clips, bins, shelf pins |
| `sanitary.json` | basins, taps, traps, bath, radiators, WC, mirror, wall cabinet, showers, drain |
| `services.json` | work bought: cutting, edging |
| `tiles.json` | tiles: size, joint, smallest piece, pattern |
