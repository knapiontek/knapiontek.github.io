Complex analysis · ODEs

Euler's Formula & Linear ODEs

Complex exponentials turn oscillations into algebra. Here they solve the damped oscillator, and the result is then checked against Euler's numerical method.

Euler's formula

e^{i\omega} = \cos\omega + i\sin\omega

At \omega=\pi this gives Euler's identity:

e^{i\pi} + 1 = 0

A damped phasor

Multiplying by a decaying exponential gives a point that spirals in towards the origin:

e^{(-\gamma+i\omega)t} = e^{-\gamma t}\left(\cos\omega t + i\sin\omega t\right)

Solving i^i

\begin{aligned} i &= \cos\tfrac{\pi}{2} + i\sin\tfrac{\pi}{2} = e^{i\pi/2} \\[4pt] i^i &= \left(e^{i\pi/2}\right)^i = e^{i\cdot i\,\pi/2} = e^{-\pi/2} \approx 0.2079 \end{aligned}

This is the principal value. Because i = e^{i(\pi/2 + 2\pi k)} for any integer k, i^i takes all the real values e^{-\pi/2 - 2\pi k}.

Homogeneous linear ODEs

ay'' + by' + cy = 0

Try an exponential, y = e^{rt}:

\left(ar^2 + br + c\right)e^{rt} = 0 \qquad\Longrightarrow\qquad ar^2 + br + c = 0

If the two roots are real and distinct, the general solution is

y = c_1e^{r_1t} + c_2e^{r_2t}

and the constants come from the initial values of y and y':

\begin{cases} y(0) = c_1 + c_2 \\ y'(0) = c_1r_1 + c_2r_2 \end{cases}

Complex roots

If b^2 < 4ac, the roots are r = -\gamma \pm i\omega, with \gamma = b/2a. Using Euler's formula:

\begin{aligned} y &= c_1e^{(-\gamma+i\omega)t} + c_2e^{(-\gamma-i\omega)t} \\[4pt] &= e^{-\gamma t}\Bigl[c_1(\cos\omega t + i\sin\omega t) + c_2(\cos\omega t - i\sin\omega t)\Bigr] \\[4pt] &= e^{-\gamma t}\Bigl[(c_1+c_2)\cos\omega t + i(c_1-c_2)\sin\omega t\Bigr] \end{aligned}

For a real solution, c_2 = \overline{c_1}, so A = c_1+c_2 and B = i(c_1-c_2) are real:

y = e^{-\gamma t}\left(A\cos\omega t + B\sin\omega t\right) = R\,e^{-\gamma t}\cos(\omega t - \varphi)

where A = R\cos\varphi and B = R\sin\varphi.

Numerical example

y'' + 2y' + 65y = 0,\qquad r^2 + 2r + 65 = 0,\qquad r = -1 \pm 8i
\begin{cases} y = e^{-t}\left(A\cos 8t + B\sin 8t\right) \\ y' = e^{-t}\left[(8B - A)\cos 8t - (8A + B)\sin 8t\right] \end{cases}

With y(0)=0.7 and y'(0)=-0.7: A = 0.7 and 8B - A = -0.7, so B = 0.

y = 0.7\,e^{-t}\cos 8t

Euler's numerical method

Reduce to a first-order system with x = y':

\begin{cases} y' = x \\ x' = -2x - 65y \end{cases}

Replacing derivatives by forward differences gives the explicit Euler method, with global error \mathcal{O}(\Delta t):

\begin{cases} y_{n+1} = y_n + x_n\,\Delta t \\ x_{n+1} = x_n + (-2x_n - 65\,y_n)\,\Delta t \end{cases}

The original page used y_{n+1} in the second line. That is the semi-implicit (symplectic) Euler method: still first order, but much better at keeping the energy of an oscillation.

x_{n+1} = x_n + (-2x_n - 65\,y_{n+1})\,\Delta t

What changed: Euler's identity had been written as e^{i\pi}-1=0. The damped exponential was missing its t. The complex-root algebra was wrong (y_1 \pm y_2 was not 2(c_1\pm c_2)\dots). The method shown was labelled explicit Euler but was really semi-implicit. A stray diagonal line ran across the spiral plot, and the step size could only be changed with numpad keys; there are now sliders.
